Detailed Description

struct drm_ivpu_cmdq_submit - Submit commands to the VPU using explicit command queue

Execute a single command buffer on a given command queue. Handles to all referenced buffer objects have to be provided in @buffers_ptr.

User space may wait on job completion using DRM_IVPU_BO_WAIT ioctl.

◆ buffers_ptr

__u64 drm_ivpu_cmdq_submit::buffers_ptr

@buffers_ptr:

A pointer to an u32 array of GEM handles of the BOs required for this job. The number of elements in the array must be equal to the value given by @buffer_count.

The first BO is the command buffer. The rest of array has to contain all BOs referenced from the command buffer.
