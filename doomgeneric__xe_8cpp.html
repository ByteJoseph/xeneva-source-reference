doomgeneric platform port for XenevaOS Implements the doomgeneric API using XenevaOS + Chitralekha APIs.

Notes:

  • The framebuffer (DG_ScreenBuffer) is owned by doomgeneric.c (allocated in doomgeneric_Create). DG_Init only falls back to allocating it if it is still NULL (e.g. direct DG_Init use).
  • Timing uses _KeGetCurrentMS (monotonic milliseconds).
  • Input polls the Chitralekha app postbox for DEODHAI_REPLY_KEY_EVENT and maps Xeneva keycodes to Doom keycodes (arrows/fire/use/esc/enter handled explicitly, the rest via ChitralekhaKeyToASCII).
