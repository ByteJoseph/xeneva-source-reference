Detailed Description

struct amdxdna_drm_query_aie_metadata - Query the metadata of the AIE hardware @col_size: The size of a column in bytes. @cols: The total number of columns. @rows: The total number of rows.

Version
: The version of the AIE hardware. @core: The metadata for all core tiles. @mem: The metadata for all mem tiles. @shim: The metadata for all shim tiles.
