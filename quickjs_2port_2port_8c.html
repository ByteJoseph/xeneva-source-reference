◆ dlmalloc_usable_size()

size_t dlmalloc_usable_size ( void *  ptr)

Port glue for QuickJS on XenevaOS (single-threaded).

libc bits quickjs.c needs that XEClib does not provide, following the original os.o semantics (msize via dlmalloc, no-op pthread cond vars, UTC local time) but completing them so the port builds from source:

  • _msize -> dlmalloc_usable_size (quickjs bookkeeping query)
  • clock_gettime for CLOCK_REALTIME/MONOTONIC via kernel wallclock/ms
  • a full gmtime/localtime (UTC) so struct tm is deterministic (XEClib's lacks tm_gmtoff/tm_zone -> quickjs Date would read slack)
  • pthread_cond* as no-ops: there is one JS thread on Xeneva
