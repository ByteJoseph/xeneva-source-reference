Detailed Description

struct drm_v3d_timestamp_query - ioctl extension for the CPU job to calculate a timestamp query

When an extension DRM_V3D_EXT_ID_TIMESTAMP_QUERY is defined, it points to this extension to define a timestamp query submission. This CPU job will calculate the timestamp query and update the query value within the timestamp BO. Moreover, it will signal the timestamp syncobj to indicate query availability.
