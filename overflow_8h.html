Computes *@d = (<< @s)

Returns true if '*@d' cannot hold the result or when '<< @s' doesn't make sense. Example conditions:

  • '<< @s' causes bits to be lost when stored in *@d.
  • '@s' is garbage (e.g. negative) or so large that the result of '<< @s' is guaranteed to be 0.
  • '' is negative.
  • '<< @s' sets the sign bit, if any, in '*@d'.
