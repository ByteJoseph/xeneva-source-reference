◆ VIRTIO_PCM_PERIOD

#define VIRTIO_PCM_PERIOD   2048

| Low Latency | 128 frame | 3 Period | 512 (period_bytes) | 1,536 (buffer_bytes) | General | 512 frame | 4 period | 2048 (period_bytes) | 8,192 (buffer_bytes)

| Media/Battery| 2048 frame | 3 period | 8,192 (period_byte) | 24,576 (buffer_bytes)

Latency profiles |-----------------------------— | Low latency | 8ms | 1 Page | General | 43 ms | 2 page |Media/Battery| 128 ms | 6 Pages |------------------------------—

Formulas: frame_bytes = channels (2=stereo) x bytes_per_sample period_bytes = period_frames x frame_bytes byffer_bytes = period_bytes x N_periods latency = buffer_bytes / (rate x frame_bytes) = N x period_frames / rate) period_frames = rate x target_latency / N

Sample bytes value U8/S8 = 1 bytes S16 = 2 bytes S24 = 3 bytes S24 in 32_BIT Container = 4 bytes S32/FLOAT32 = 4 bytes FLOAT64 = 8 bytes
