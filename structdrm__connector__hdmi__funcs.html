const struct drm_edid *(* drm_connector_hdmi_funcs::read_edid) (struct drm_connector *connector)

@read_edid:

This callback is used by the framework as a replacement for reading the EDID from connector->ddc. It is still recommended to provide connector->ddc instead of implementing this callback. Returned EDID should be freed via the drm_edid_free().

The @read_edid callback is optional.

Returns: Valid EDID on success, NULL in case of failure.

enum drm_mode_status(* drm_connector_hdmi_funcs::tmds_char_rate_valid) (const struct drm_connector *connector, const struct drm_display_mode *mode, unsigned long long tmds_rate)

@tmds_char_rate_valid:

This callback is invoked at atomic_check time to figure out whether a particular TMDS character rate is supported by the driver.

The @tmds_char_rate_valid callback is optional.

Returns:

Either &drm_mode_status.MODE_OK or one of the failure reasons in &enum drm_mode_status.
