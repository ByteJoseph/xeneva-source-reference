Detailed Description

struct drm_monitor_range_info - Panel's Monitor range in EDID for &drm_display_info

This struct is used to store a frequency range supported by panel as parsed from EDID's detailed monitor range descriptor block.

@min_vfreq: This is the min supported refresh rate in Hz from EDID's detailed monitor range. @max_vfreq: This is the max supported refresh rate in Hz from EDID's detailed monitor range
