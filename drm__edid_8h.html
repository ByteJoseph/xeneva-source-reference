drm_edid_encode_panel_id - Encode an ID for matching against drm_edid_get_panel_id() @vend_chr_0: First character of the vendor string. @vend_chr_1: Second character of the vendor string. @vend_chr_2: Third character of the vendor string. @product_id: The 16-bit product ID.

This is a macro so that it can be calculated at compile time and used as an initializer.

For instance: drm_edid_encode_panel_id('B', 'O', 'E', 0x2d08) => 0x09e52d08

Return: a 32-bit ID per panel.
