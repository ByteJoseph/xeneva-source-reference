◆ AuConsolePresentRect()

void AuConsolePresentRect ( int x,
int y,
int w,
int h )

AuConsolePresentRect – hand an explicit damage rectangle to the scanout mirror installed by AuConsoleSetPresentHook.

The text console marks its own damage and flushes through AuConsoleFlushMirror(); this entry is for userspace, which paints into the mapped framebuffer directly and has no way to say "this much changed" other than SCREEN_UPDATE. Unlike the text mirror it is deliberately not gated on display_owned: the request comes from the process that owns the display, and muzzling it would leave the scanout frozen on its last text frame once the compositor takes over.
