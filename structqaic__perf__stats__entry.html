Detailed Description

struct qaic_perf_stats_entry - Defines a BO perf info. @handle: In. GEM handle of the BO to get perf stats for. @queue_level_before: Out. Number of elements in the queue before this BO was submitted. @num_queue_element: Out. Number of elements added to the queue to submit this BO. @submit_latency_us: Out. Time taken by the driver to submit this BO. @device_latency_us: Out. Time taken by the device to execute this BO. @pad: Structure padding. Must be 0.
