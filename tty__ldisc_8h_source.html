4/*
5 * DCL <linux/tty_ldisc.h> -- the line discipline interface, plus the
6 * ld_semaphore it is serialised on.
7 *
8 * Ported from mainline v7.2. The line discipline is the layer that decides
9 * what a byte stream *means*: n_tty (cooked mode) turns 0x7f into a backspace
10 * and a line into an input record, while raw mode hands bytes through
11 * untouched. tty_ldisc.c registers the set and tty_ldisc_ref()/deref() guard
12 * a caller's use of one while it can be swapped underneath (TIOCSETD).
13 *
14 * The struct definitions are exact -- tty_ldisc_ops is the table n_tty.c
15 * fills in, and every member is a member a ported file either assigns or
16 * calls. The optional hooks are all present as function pointers; mainline
17 * explicitly documents them as allowed to be NULL, and tty_buffer.c:397/428
18 * tests receive_buf and lookahead_buf for exactly that reason.
19 *
20 * ld_semaphore lives here because struct tty_struct embeds it by value
21 * (tty.h), so the complete type has to exist before tty.h can. It is
22 * mainline's layout with raw_spinlock_t spelled spinlock_t: DCL's spinlock_t
23 * *is* the raw lock (typedef int spinlock_t, kernel.h:43), so the distinction
24 * mainline draws between raw and non-raw has no referent here.
25 *
26 * init_ldsem() keeps mainline's lock_class_key argument. It used to drop it
27 * -- the reasoning was that there is no lockdep to give a key to -- but the
28 * argument belongs to tty_ldsem.c's *definition*, which is vendored and
29 * cannot be edited to match, so the declaration follows it instead. The key
30 * it passes is a per-call-site static, exactly as mainline's macro mints one,
31 * and lockdep.h's `struct lock_class_key { }` makes it an object with an
32 * address rather than a notion. That is all the argument is ever asked to
33 * be: lockdep_set_class() evaluates it and drops it.
34 */

93/*
94 * The nested pair, exactly as mainline splits them at
95 * include/linux/tty_ldisc.h:45. It matters which arm exists: tty_ldsem.c
96 * puts both *definitions* inside `#ifdef CONFIG_DEBUG_LOCK_ALLOC` (:398-413),
97 * so with lockdep off there is no function to declare. Declaring one
98 * anyway compiled fine and failed at link, on a symbol only tty_ldisc.c:295
99 * names -- the plain declaration never notices that the definition it
100 * promises is conditional.
101 *
102 * The #else arm is mainline's, and it is a macro rather than an inline for
103 * the usual reason: it drops the subclass argument entirely. With lockdep
104 * off the subclass is only ever a note to lockdep about which of several
105 * identical semaphores this is (LDISC_SEM_OTHER at the call site), so the
106 * nested and non-nested take are the same take, and the macro says so by
107 * literally rewriting one into the other.
108 *
109 * CONFIG_DEBUG_LOCK_ALLOC is not in <linux/autoconf.h> at all, which is what
110 * sends this to the #else arm -- `#ifdef` reads absence as false, unlike
111 * IS_ENABLED() in kernel.h, which reads it as a compile error.
112 */
