Detailed Description

struct drm_fb_helper_funcs - driver callbacks for the fbdev emulation library

Driver callbacks used by the fbdev emulation helper library.

Member Data Documentation

◆ fb_dirty

int(* drm_fb_helper_funcs::fb_dirty) (struct drm_fb_helper *helper, struct drm_clip_rect *clip)

@fb_dirty:

Driver callback to update the framebuffer memory. If set, fbdev emulation will invoke this callback in regular intervals after the framebuffer has been written.

This callback is optional.

Returns: 0 on success, or an error code otherwise.

◆ fb_restore

void(* drm_fb_helper_funcs::fb_restore) (struct drm_fb_helper *helper)

@fb_restore:

Driver callback to restore internal fbdev state. If set, fbdev emulation will invoke this callback after restoring the display mode.

Only for i915. Do not use in new code.

void(* drm_fb_helper_funcs::fb_set_suspend) (struct drm_fb_helper *helper, bool suspend)

@fb_set_suspend:

Driver callback to suspend or resume, if set, fbdev emulation will invoke this callback during suspend and resume. Driver should call fb_set_suspend() from their implementation. If not set, fbdev emulation will invoke fb_set_suspend() directly.

Only for i915. Do not use in new code.
