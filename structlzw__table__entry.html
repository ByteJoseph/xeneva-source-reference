Detailed Description

LZW table entry.

Records in the table are composed of 1 or more entries. Entries refer to the entry they extend which can be followed to compose the complete record. To compose the record in reverse order, take the value from each entry, and move to the entry it extends. If the extended entries index is < the current clear_code, then it is the last entry in the record.
