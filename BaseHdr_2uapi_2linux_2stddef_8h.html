__struct_group() - Create a mirrored named and anonyomous struct

@TAG: The tag name for the named sub-struct (usually empty) @NAME: The identifier name of the mirrored sub-struct @ATTRS: Any struct attributes (usually empty) @MEMBERS: The member declarations for the mirrored structs

Used to create an anonymous union of two structs with identical layout and size: one anonymous and one named. The former's members can be used normally without sub-struct naming, and the latter can be used to reason about the start, end, and size of the group of struct members. The named struct can also be explicitly tagged for layer reuse (C only), as well as both having struct attributes appended.
