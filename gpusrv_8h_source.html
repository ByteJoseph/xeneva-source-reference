1/* GPUSRV=1: asynchronous virtio-gpu presentation over /dev/gpusrv.
2 *
3 * /dev/graph maps a kernel-owned, tightly packed desktop framebuffer. It is
4 * stable across server restarts and mirrored to GOP on each damage update.
5 * ACQUIRE requires the caller's hwdev capability for 1af4:1050. The ABI never
6 * returns a physical framebuffer address owned by the kernel: the server
7 * supplies DMA backing pages allocated through its own /dev/hwdev capability.
8 * TAKE copies pending damage from the stable kernel framebuffer into that
9 * backing, then freezes the frame until ACK.
10 * Only one frame may be in flight. New damage coalesces while it is busy.
11 * The server must reset the device before ACQUIRE and close its hwdev handle
12 * after any failed/timed-out command. It must never ACK unfinished device I/O.
13 * The kernel never waits for the server and never frees either framebuffer.
14 */
