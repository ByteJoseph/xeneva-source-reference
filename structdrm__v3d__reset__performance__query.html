Detailed Description

struct drm_v3d_reset_performance_query - ioctl extension for the CPU job to reset performance queries

When an extension DRM_V3D_EXT_ID_CPU_RESET_PERFORMANCE_QUERY is defined, it points to this extension to define a reset performance submission. This CPU job will reset the performance queries by resetting the values of the performance monitors. Moreover, it will reset the syncobj to reset query availability.
