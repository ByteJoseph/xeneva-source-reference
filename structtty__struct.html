Detailed Description

struct tty_struct - state associated with a tty while open

The field comments are mainline's, abridged where the comment only restated the field name. What is worth knowing before touching this struct: count is openers, kref is references, and they are not the same number – count reaching zero cancels work and drops a kref, but the tty is freed by whoever held the last kref, which may be a different path entirely.
