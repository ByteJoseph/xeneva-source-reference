Detailed Description

struct qaic_sem - Defines a semaphore command for a BO slice. @val: In. Only lower 12 bits are valid. @index: In. Only lower 5 bits are valid. @presync: In. 1 if presync operation, 0 if postsync. @cmd: In. One of QAIC_SEM_*. @flags: In. Bitfield. See QAIC_SEM_INSYNCFENCE and QAIC_SEM_OUTSYNCFENCE @pad: Structure padding. Must be 0.
