NetSurf CSS wrapper for XenevaOS (Phase 1+2).

Thin element tree + libcss select client. The HTML pass builds NsCssNodes as it scans tags; each node is selected against the UA + author sheets on open (ancestors are always selected first, so inheritance composes). Inline style="" attributes parse to per-node author sheets.

Exposes only what the readability renderer needs: text color (0xAARRGGBB, libcss css_color layout matches Chitralekha pixels), font size in px, and extra blank lines from vertical margins.
