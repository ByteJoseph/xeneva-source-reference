typedef const uint32_t *(* NsImageLookupFn) (const char *src, int *width, int *height, int *intrinsic_width, int *intrinsic_height)

Block/inline layout and painting for the XenevaOS NetSurf renderer.

Takes the NsCssNode tree produced by dom.c, resolves libcss computed styles into boxes, wraps inline text with Chitralekha font metrics and paints the resulting display list. Scrolling is in pixels.
