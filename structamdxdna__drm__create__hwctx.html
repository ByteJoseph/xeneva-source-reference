Detailed Description

struct amdxdna_drm_create_hwctx - Create hardware context. @ext: MBZ. @ext_flags: MBZ. @qos_p: Address of QoS info. @umq_bo: BO handle for user mode queue(UMQ). @log_buf_bo: BO handle for log buffer. @max_opc: Maximum operations per cycle. @num_tiles: Number of AIE tiles. @mem_size: Size of AIE tile memory. @umq_doorbell: Returned offset of doorbell associated with UMQ. @handle: Returned hardware context handle. @syncobj_handle: Returned syncobj handle for command completion.
