Detailed Description

struct mipi_dsi_device_info - template for creating a mipi_dsi_device @type: DSI peripheral chip type @channel: DSI virtual channel assigned to peripheral @node: pointer to OF device node or NULL

This is populated and passed to mipi_dsi_device_new to create a new DSI device
