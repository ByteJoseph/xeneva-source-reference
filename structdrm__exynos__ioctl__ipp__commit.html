Detailed Description

Perform image processing described by array of drm_exynos_ipp_task_* structures (parameters array).

@ipp_id: id of IPP module to run the task @flags: bitmask of drm_exynos_ipp_flag values @reserved: padding @params_size: size of parameters array (in bytes) @params_ptr: pointer to parameters array or NULL @user_data: (optional) data for drm event
