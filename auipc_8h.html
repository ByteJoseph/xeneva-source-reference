auipc.h – generic kernel IPC: named endpoints with synchronous call/reply.

A server (MISC_DAEMONS group) creates a named endpoint on /dev/ipc. Any process the endpoint's ACL admits can connect by name and CALL it: the kernel copies the request into a queue, wakes the server, and the caller sleeps until the server REPLYs, the timeout expires, or the server dies. The server learns the caller's pid/uid/gid from the kernel, never from the message.

Blocking calls cannot return a value after they sleep (the syscall frame is resumed, not the C stack), so the sleeping operations are paired with a non-blocking one that delivers the data:

client: IPC_IOC_CALL (sleeps) then IPC_IOC_FETCH (reply or error) server: IPC_IOC_WAIT (sleeps) then IPC_IOC_RECV (request or empty) IPC_IOC_REPLY

Fields named status are the result of the sleeping call; read them after it.
