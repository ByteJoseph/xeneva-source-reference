Detailed Description

Get IPP hardware capabilities and supported image formats.

@ipp_id: id of IPP module to query @capabilities: bitmask of drm_exynos_ipp_capability (set by driver) @reserved: padding @formats_count: size of formats array (in entries) / number of filled formats (set by driver) @formats_ptr: pointer to formats array or NULL
