NetSurf QuickJS host for XenevaOS.

Runs page <script> bodies in document order while the readability pass parses. No DOM tree yet: the host exposes a scripting shell that can run logic and emit text through the renderer – console lines and document.write output land inline at the position the script executes.

Exposes only QuickJS's core intrinsics (Math/JSON/RegExp/Intl...); the DOM, CSSOM, images and network fetchers are future work (README).
