netsrv.h – shared kernel/user ABI between the kernel network proxy (KernelAA64/Net/netproxy.c) and a user-space NIC server (Process/netsrv).

The server allocates one DMA buffer through /dev/hwdev, lays a NetRingHdr at its start followed by two rings of fixed-size frame slots, and passes the buffer's physical address to /dev/netsrv (NETSRV_IOC_ATTACH). The kernel only accepts a buffer that is one of the caller's own DMA allocations. The kernel then registers the adapters "e1000" and "virtio-net" (what the in-kernel driver registered) and the network stack cannot tell the difference.

TX ring: kernel produces (tx_head), server consumes (tx_tail) RX ring: server produces (rx_head), kernel consumes (rx_tail)

head/tail are free-running slot counters. A slot is a u32 frame length, a u32 pad, then the Ethernet frame. The kernel never trusts a length read from the ring and copies a frame out before parsing it.
