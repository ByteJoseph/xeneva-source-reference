◆ AuRemoveNetAdapter()

int AuRemoveNetAdapter ( char *  name)

AuRemoveNetAdapter – the driver behind an adapter is going away. The node itself stays (open handles and the stack may still point at it) but becomes a dead interface: writes are dropped, the link is down, and nothing points into the departing driver any more. A later AuAddNetAdapter with the same name revives it.

Returns
0 if it existed, -1 otherwise
