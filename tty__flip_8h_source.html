4/*
5 * DCL <linux/tty_flip.h> -- the driver-facing side of the flip buffer.
6 *
7 * Ported from mainline v7.2. This is the API a UART interrupt handler calls:
8 * tty_insert_flip_char() puts one byte in, tty_flip_buffer_push() makes it
9 * visible. Everything else in the header is convenience layered on
10 * __tty_insert_flip_string_flags().
11 *
12 * The fast path in tty_insert_flip_char() is worth reading slowly, because
13 * the flag byte is the subtle part:
14 *
15 * change = !tb->flags && (flag != TTY_NORMAL);
16 * if (!change && tb->used < tb->size) { ... store ... return 1; }
17 *
18 * A buffer created without flags (tty_prepare_flip_string(), and every
19 * normal-character allocation) has no flag array at all -- flag_buf_ptr()
20 * would point into the next buffer's memory. So a non-NORMAL flag forces an
21 * allocation for a flags-capable buffer before anything is written; and once
22 * a flags buffer is in use, each byte's flag is written *only if* the buffer
23 * is flagged, which is what the inner `if (tb->flags)` checks. Getting this
24 * wrong does not crash -- it silently records every byte as TTY_NORMAL, and
25 * a break or parity error simply never reaches the ldisc.
26 */
