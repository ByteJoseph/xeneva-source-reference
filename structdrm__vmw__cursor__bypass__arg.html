Detailed Description

struct drm_vmw_cursor_bypass_arg

@flags: Flags. @crtc_id: Crtc id, only used if DMR_CURSOR_BYPASS_ALL isn't passed. @xpos: X position of cursor. @ypos: Y position of cursor. @xhot: X hotspot. @yhot: Y hotspot.

Argument to the DRM_VMW_CURSOR_BYPASS Ioctl.
