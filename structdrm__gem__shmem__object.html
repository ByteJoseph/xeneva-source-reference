◆ pages_pin_count

refcount_t drm_gem_shmem_object::pages_pin_count

@pages_pin_count:

Reference count on the pinned pages table.

Pages are hard-pinned and reside in memory if count greater than zero. Otherwise, when count is zero, the pages are allowed to be evicted and purged by memory shrinker.
