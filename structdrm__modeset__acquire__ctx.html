Detailed Description

struct drm_modeset_acquire_ctx - locking context (see ww_acquire_ctx) @ww_ctx: base acquire ctx @contended: used internally for -EDEADLK handling @stack_depot: used internally for contention debugging @locked: list of held locks @trylock_only: trylock mode used in atomic contexts/panic notifiers @interruptible: whether interruptible locking should be used.

Each thread competing for a set of locks must use one acquire ctx. And if any lock fxn returns -EDEADLK, it must backoff and retry.
