Detailed Description

struct drm_v3d_copy_timestamp_query - ioctl extension for the CPU job to copy query results to a buffer

When an extension DRM_V3D_EXT_ID_CPU_COPY_TIMESTAMP_QUERY is defined, it points to this extension to define a copy timestamp query submission. This CPU job will copy the timestamp queries results to a BO with the offset and stride defined in the extension.
