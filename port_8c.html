CssLibs port shims for XenevaOS.

bsearch: used once by libparserutils (charset/aliases.c). XEClib does not provide it, so a small self-contained binary search lives here.

abort trap: XEClib's abort() exits silently, which makes libcss asserts undebuggable (a dead window looks "stuck"). Route port aborts through here so the serial log names the call site; resolve with llvm-objdump on the linked binary.
