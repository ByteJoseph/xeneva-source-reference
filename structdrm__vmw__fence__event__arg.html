Detailed Description

struct drm_vmw_fence_event_arg

@fence_rep: Pointer to fence_rep structure cast to __u64 or 0 if the fence is not supposed to be referenced by user-space. @user_info: Info to be delivered with the event. @handle: Attach the event to this fence only. @flags: A set of flags as defined above.
