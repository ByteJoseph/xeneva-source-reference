Shared kernel/user ABI between the kernel sound proxy card and a user-space sound server (Process/sndsrv).

The server allocates one DMA buffer through /dev/hwdev, lays a SndRingHdr at its start and a power-of-two data area at SNDSRV_DATA_OFFSET, then passes the buffer's physical address to /dev/sndsrv (SNDSRV_IOC_ATTACH). The kernel only accepts a buffer that really is one of the caller's own DMA allocations. From then on the kernel sound card "virtio-sound" copies the mixer's PCM into the ring (single producer) and the server drains it into the device (single consumer). head/tail are free-running byte counters.
