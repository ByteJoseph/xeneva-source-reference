Detailed Description

struct drm_plane - central DRM plane control structure

Planes represent the scanout hardware of a display block. They receive their input data from a &drm_framebuffer and feed it to a &drm_crtc. Planes control the color conversion, see Plane Composition Properties_ for more details, and are also involved in the color conversion of input pixels, see Color Management Properties_ for details on that.

◆ state

struct drm_plane_state* drm_plane::state

@state:

Current atomic state for this plane.

This is protected by @mutex. Note that nonblocking atomic commits access the current plane state without taking locks. Either by going through the &struct drm_atomic_commit pointers, see for_each_oldnew_plane_in_state(), for_each_old_plane_in_state() and for_each_new_plane_in_state(). Or through careful ordering of atomic commit operations as implemented in the atomic helpers, see &struct drm_crtc_commit.
