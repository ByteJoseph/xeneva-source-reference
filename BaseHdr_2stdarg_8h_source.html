42 * __clang__ is deliberately *not* tested above. mainline's
43 * <linux/stdarg.h> forwards here, so whichever type is typedef'd
44 * below is the one every drm source sees -- and the two drm users
45 * want opposite things from it. drm_print.c needs the builtins
46 * (clang's va_start rejects a hand-rolled pointer), and
47 * KernelAA64/Drivers/uart.c:129 needs the flat one, because
48 * `va_list args = ((va_list)reg_save_area + 8)` only compiles when
49 * va_list is a pointer it can cast and add to.
50 *
51 * XEClib's userspace copy of this header
52 * (Libs/XEClib/includes/stdarg.h) *has* moved arm-64 to the builtins,
53 * with a note naming the forwarded-va_list cases the pointer walk gets

55 * uart.c's register-save-area walk -- not this typedef back and forth.
