Detailed Description

struct amdxdna_drm_bo_usage - all types of BO usage BOs managed by XRT/SHIM/driver is counted as internal. Others are counted as external which are managed by applications.

Among all types of BOs: AMDXDNA_BO_DEV_HEAP - is counted for internal. AMDXDNA_BO_SHARE - is counted for external. AMDXDNA_BO_CMD - is counted for internal. AMDXDNA_BO_DEV - is counted by heap_usage only, not internal or external. It does not add to the total memory footprint since its mem comes from heap which is already counted as internal.
