Detailed Description

struct drm_vc4_create_shader_bo - ioctl argument for creating VC4 shader BOs.

Since allowing a shader to be overwritten while it's also being executed from would allow privlege escalation, shaders must be created using this ioctl, and they can't be mmapped later.
