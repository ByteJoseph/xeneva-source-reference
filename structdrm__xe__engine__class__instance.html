Detailed Description

struct drm_xe_engine_class_instance - instance of an engine class

It is returned as part of the &struct drm_xe_engine, but it also is used as the input of engine selection for both &struct drm_xe_exec_queue_create and &struct drm_xe_query_engine_cycles

The @engine_class can be:

  • DRM_XE_ENGINE_CLASS_RENDER
  • DRM_XE_ENGINE_CLASS_COPY
  • DRM_XE_ENGINE_CLASS_VIDEO_DECODE
  • DRM_XE_ENGINE_CLASS_VIDEO_ENHANCE
  • DRM_XE_ENGINE_CLASS_COMPUTE
  • DRM_XE_ENGINE_CLASS_VM_BIND - Kernel only classes (not actual hardware engine class). Used for creating ordered queues of VM bind operations.
