: the name of the completion

DECLARE_COMPLETION - define a completion at file scope

mainline's is struct completion name = { 0 } (or the ONSTACK twin, which differs only in that mainline's ONSTACK runs a lockdep ctor). virtio_console.c:61 writes static DECLARE_COMPLETION(early_console_added);, and with no macro the line parses as an untyped function declaration – the same pair of errors DEFINE_SPINLOCK produces – so early_console_added() has no variable behind it by the time :1571 does complete(&early_console_added).

= { 0 } rather than = { } because a braceless initialiser on a struct whose first member is unsigned int is a GNU extension, and this target is built with clang.
