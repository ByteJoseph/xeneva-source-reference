Detailed Description

struct drm_vmw_mksstat_add_arg

@stat: Pointer to user-space stat-counters array, page-aligned. @info: Pointer to user-space counter-infos array, page-aligned. @strs: Pointer to user-space stat strings, page-aligned. @stat_len: Length in bytes of stat-counters array. @info_len: Length in bytes of counter-infos array. @strs_len: Length in bytes of the stat strings, terminators included. @description: Pointer to instance descriptor string; will be truncated to MKS_GUEST_STAT_INSTANCE_DESC_LENGTH chars. @id: Output identifier of the produced record; -1 if error.

Argument to the DRM_VMW_MKSSTAT_ADD ioctl.
