struct drm_ivpu_bo_create - Create BO backed by SHMEM

Create GEM buffer object allocated in SHMEM memory.

Member Data Documentation

◆ flags

__u32 drm_ivpu_bo_create::flags

@flags:

Supported flags:

DRM_IVPU_BO_HIGH_MEM:

Allocate VPU address from >4GB range. Buffer object with vpu address >4GB can be always accessed by the VPU DMA engine, but some HW generation may not be able to access this memory from then firmware running on the VPU management processor. Suitable for input, output and some scratch buffers.

DRM_IVPU_BO_MAPPABLE:

Buffer object can be mapped using mmap().

DRM_IVPU_BO_CACHED:

Allocated BO will be cached on host side (WB) and snooped on the VPU side. This is the default caching mode.

DRM_IVPU_BO_UNCACHED:

Not supported. Use DRM_IVPU_BO_WC instead.

DRM_IVPU_BO_WC:

Allocated BO will use write combining buffer for writes but reads will be uncached.
