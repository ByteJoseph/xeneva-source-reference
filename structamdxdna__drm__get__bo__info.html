Detailed Description

struct amdxdna_drm_get_bo_info - Get buffer object information. @ext: MBZ. @ext_flags: MBZ. @handle: DRM buffer object handle. @pad: MBZ. @map_offset: Returned DRM fake offset for mmap(). @vaddr: Returned user VA of buffer. 0 in case user needs mmap(). @xdna_addr: Returned XDNA device virtual address.
