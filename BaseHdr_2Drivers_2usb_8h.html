void AuXhciStartPolling ( void )
extern

AuXhciStartPolling – start the HID and port-change consumers.

Controller enumeration happens early, while the USB device objects and rings can still be built. Kernel threads, however, are inserted into the scheduler's thread list, and AuSchedulerInitialize() resets that list. Creating them afterwards is what keeps the poll threads alive.
