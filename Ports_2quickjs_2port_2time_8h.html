time.h shim for the QuickJS port on XenevaOS.

XEClib's real time.h skips struct tags (typedef-only), lacks tm_gmtoff / tm_zone, and declares gettimeofday as (timeval*). quickjs.c needs classic <time.h> interfaces, so the QuickJS port build resolves <time.h> to this header. localtime/gmtime are implemented in port/port.c; the rest stay XEClib's.
