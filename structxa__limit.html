Detailed Description

struct xa_limit - Represents a range of IDs. @min: The lowest ID to allocate (inclusive). @max: The maximum ID to allocate (inclusive).

This structure is used either directly or via the XA_LIMIT() macro to communicate the range of IDs that are valid for allocation. Three common ranges are predefined for you:

  • xa_limit_32b - [0 - UINT_MAX]
  • xa_limit_31b - [0 - INT_MAX]
  • xa_limit_16b - [0 - USHRT_MAX]
