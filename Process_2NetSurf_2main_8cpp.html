NetSurf bootstrap browser for XenevaOS.

Staging frontend, not upstream NetSurf core yet: a Chitralekha window with a URL bar + Go button, HTTP/1.0 fetch over XEClib sockets (same path as Process/http/curl.exe), and crude HTML-to-text rendering into a textbox.

Real NetSurf (libcss/libdom/libparserutils) + HTTPS still need the musl shim and an mbedTLS port first – https:// URLs get an honest message.
