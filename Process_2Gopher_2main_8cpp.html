Gopher client for XenevaOS (terminal app, RFC 1436).

Usage: gopher <host> [port] [selector] (default port 70)

Renders menus with numbered links; type a number to follow it. Type 7 (search) prompts for a query. 'u <host>' switches servers, 'q' quits. Text (0) and directory (1) listings render inline.
