Detailed Description

Context for reading LZW data.

LZW data is split over multiple sub-blocks. Each sub-block has a byte at the start, which says the sub-block size, and then the data. Zero-size sub-blocks have no data, and the biggest sub-block size is 255, which means there are 255 bytes of data following the sub-block size entry.

Note that an individual LZW code can be split over up to three sub-blocks.
