Detailed Description

struct drm_suballoc - Sub-allocated range @olist: List link for list of allocated ranges. @flist: List linkk for the manager fenced allocated ranges queues. @manager: The drm_suballoc_manager. @soffset: Start offset. @eoffset: End offset + 1 so that @eoffset - @soffset = size. @fence: The fence protecting the allocation.
