#define FSSRV_ENDPOINT   "fs"

fssrv.h – wire protocol between the kernel's /srv file-system proxy (KernelAA64/Fs/srvfs.c) and a user-space file server (Process/fssrv).

The protocol is stateless and path-based, like NFS: there are no server-side handles, so nothing leaks when a client closes a file or dies. Every request travels over the generic kernel IPC to the endpoint FSSRV_ENDPOINT; the kernel stamps each one with the calling process's uid, which is what the server enforces permissions against. Data follows the fixed header in the same message.
