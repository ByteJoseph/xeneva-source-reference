Detailed Description

struct ff_haptic_effect @hid_usage: hid_usage according to Haptics page (WAVEFORM_CLICK, etc.) @vendor_id: the waveform vendor ID if hid_usage is in the vendor-defined range @vendor_waveform_page: the vendor waveform page if hid_usage is in the vendor-defined range @intensity: strength of the effect as percentage @repeat_count: number of times to retrigger effect @retrigger_period: time before effect is retriggered (in ms)
