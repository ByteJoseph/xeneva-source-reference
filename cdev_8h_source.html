15 * DCL delta: mainline declares `struct cdev` here, in its own words. DCL
16 * already carries it in <linux/fs.h> (:141), measured against linux-7.2.6 at
17 * kobj 0 / owner 64 / ops 72 / list 80 / dev 96 / count 100 / size 104, and
18 * pinned there by static asserts because fs.h's layout is the ABI the rest of
19 * the tree is compiled against. Two definitions of the same struct in one
20 * translation unit is a hard redefinition error, and fs.h is the one file that
21 * must not move -- so this header yields and routes instead: the struct comes
22 * from where it is authoritative, and only the function declarations, which
23 * DCL/linux_cdev_shim.c actually implements, are spelled here.
