Detailed Description

struct drm_v3d_multi_sync - ioctl extension to add support multiples syncobjs for commands submission.

When an extension of DRM_V3D_EXT_ID_MULTI_SYNC id is defined, it points to this extension to define wait and signal dependencies, instead of single in/out sync entries on submitting commands. The field flags is used to determine the stage to set wait dependencies.
