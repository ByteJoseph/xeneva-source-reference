Detailed Description

struct drm_vmw_gb_surface_create_req

@svga3d_flags: SVGA3d surface flags for the device. @format: SVGA3d format. @mip_level: Number of mip levels for all faces. @drm_surface_flags Flags as described above. @multisample_count Future use. Set to 0. @autogen_filter Future use. Set to 0. @buffer_handle Buffer handle of backup buffer. SVGA3D_INVALID_ID if none. @base_size Size of the base mip level for all faces. @array_size Must be zero for non-DX hardware, and if non-zero svga3d_flags must have proper bind flags setup.

Input argument to the DRM_VMW_GB_SURFACE_CREATE Ioctl. Part of output argument for the DRM_VMW_GB_SURFACE_REF Ioctl.
