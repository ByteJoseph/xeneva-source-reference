4/*
5 * DCL <linux/ioport.h> -- I/O window bookkeeping.
6 *
7 * Xeneva has no I/O region allocator: there is no ioport_resource tree, no
8 * sparse iomem map, and no enforcement of exclusive claims. The serial code
9 * still asks for regions (8250_pci.c:2904 request_mem_region, :2917
10 * request_region, plus serial_core.c's resource bookkeeping), and the answer
11 * to a claim has to be truthful: mainline treats a NULL return as "someone
12 * else owns this window" and unwinds.
13 *
14 * So the claim is recorded in a small table with overlap detection and the
15 * window is only refused if it genuinely collides -- a real check, just over
16 * an eight-entry list instead of a resource tree. Reporting success blindly
17 * would let two drivers walk over the same registers, which on a UART means
18 * two writers corrupting each other's LCR; reporting failure blindly would
19 * leave every port unbound. Bodies in DCL/linux_irq_shim.c.
20 *
21 * __iomem is already defined (empty) in <linux/kernel.h>.
22 */
23

26/*
27 * The three tree links, in mainline's order, plus the four fields this file
28 * already had. They were added for drm_cache.c:204, which walks the I/O
29 * memory map as a *tree* -- `for (tmp = iomem_resource.child; tmp;
30 * tmp = tmp->sibling)` -- to find the highest mapped address and decide
31 * whether a device with a narrower DMA mask would need bounce buffers.
32 *
33 * A struct with only start/end/name/flags would compile at the `child` read
34 * and fail at the `sibling` one, and the two errors point at different tokens
35 * in one expression, which is the shape a missing member has when the first
36 * dereference happens to find something.
37 *
38 * The tree is empty -- iomem_resource is defined in a shim with a NULL child
39 * -- because Xeneva maps nothing through request_mem_region() and has no
40 * SWIOTLB to bounce against. So the loop does not run, max_iomem keeps its
41 * initial 0, and drm_need_swiotlb() answers false, which is the correct
42 * answer for this kernel rather than a stubbed one.
43 */
