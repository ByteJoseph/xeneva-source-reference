◆ NS_CSS_BASE_PX

#define NS_CSS_BASE_PX   14

NetSurf CSS wrapper implementation. See css.h.

Follows libcss test/select.c: stylesheet params, select handler vtable, select-then-compose walk, UA default hints. Unsupported selectors (sibling combinators, dynamic pseudo-classes, ...) report no-match, which is legal: those rules simply don't apply.
