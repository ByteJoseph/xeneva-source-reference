Dirty tile map: the screen as a bitmap of 32x32 tiles.

  • DirtyTilesMark O(rows touched x (1 + columns / 64)) – no merging
  • DirtyTilesEmit bit-scans each row for runs of set tiles and extends a rectangle from the row above when the run is identical, so a filled area comes out as one rectangle: O(words + runs); clears the map Compared with merging rectangles pairwise (transitive merge restarts are O(R^2) or worse per insert) the cost no longer depends on how many damaged rectangles arrive in a frame.
