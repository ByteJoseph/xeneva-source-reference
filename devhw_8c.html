◆ HW_MAX_CLAIMS

#define HW_MAX_CLAIMS   32

devhw.c – /dev/hwdev: capability-gated hardware access for user-space drivers

See BaseHdr/hwdev.h for the contract. Summary: PCI_OPEN on the controller node returns a new fd that is a CAP_OBJ_PCIDEV capability for one PCI function; config access, BAR mapping and DMA buffers are ioctls on that fd, each bounded by the device. The capability table releases everything when the fd is closed or the process exits (AuHwdevCapReleased).
