devgpu.c – thin kernel proxy for the user-space virtio-GPU server.

The server owns the PCI function through /dev/hwdev. This node keeps the compositor-facing framebuffer stable and performs the one safety-critical bridge operation: copying a bounded damage rectangle into DMA memory that belongs to the server's exact GPU capability. The kernel never submits a virtio command and never waits for the server.
