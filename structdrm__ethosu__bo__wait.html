Detailed Description

struct drm_ethosu_wait_bo - ioctl argument for waiting for completion of the last DRM_ETHOSU_SUBMIT on a BO.

This is useful for cases where multiple processes might be rendering to a BO and you want to wait for all rendering to be completed.
