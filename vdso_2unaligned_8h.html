__get_unaligned_t - read an unaligned value from memory. @type: the type to load from the pointer. @ptr: the pointer to load from.

Use memcpy to affect an unaligned type sized load avoiding undefined behavior from approaches like type punning that require -fno-strict-aliasing in order to be correct. As type may be const, use __unqual_scalar_typeof to map to a non-const type - you can't memcpy into a const type. The __get_unaligned_ctrl_type gives __unqual_scalar_typeof its required expression rather than type, a pointer is used to avoid warnings about mixing the use of 0 and NULL. The void* cast silences ubsan warnings.
