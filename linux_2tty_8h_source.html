4/*
5 * DCL <linux/tty.h> -- struct tty_struct and the tty core's public surface.
6 *
7 * Ported from mainline v7.2. This used to declare exactly one thing (tty_init,
8 * the placeholder in DCL/linux_mm_shim.c); it is now the real header, because
9 * tty_buffer.c is the first staged file that needs a tty to look like a tty.
10 *
11 * Three deliberate departures, each for a reason that is visible in the code:
12 *
13 * 1. The CONFIG_TTY / CONFIG_AUDIT conditionals are written out in the
14 * "enabled" direction. DCL's configuration lives in <linux/autoconf.h>
15 * and has no CONFIG_TTY -- it was never needed, because tty_init() was a
16 * stub. Writing only the enabled branch means the declarations that
17 * tty_io.c and serial_core.c call always exist, instead of silently
18 * becoming static inline stubs that return -ENODEV. CONFIG_AUDIT's block
19 * is written out as the "not enabled" (inline no-op) branch: there is no
20 * audit subsystem here at all, so tty_audit_* must be a no-op rather than
21 * a link error.
22 *
23 * 2. tty_termios_baud_rate()/tty_termios_encode_baud_rate()/tty_termios_
24 * copy_hw() are *not* re-declared here. mainline declares them in this
25 * header and defines them in drivers/tty/tty_termios.c; DCL defines them
26 * as static inline in <linux/linux/termios.h> (one shared table, both
27 * directions). An external declaration next to a static inline definition
28 * of the same name is a compile error -- "non-static declaration follows
29 * static declaration" -- so the declaration goes away and the definition
30 * stays where it can be shared by every caller.
31 *
32 * 3. The N_* line discipline numbers come from uapi/linux/tty.h in mainline.
33 * DCL has no uapi layer, so they live here. n_tty.c and tty_ldisc.c are
34 * the only staged files that need them, and both include this header.
35 *
36 * The struct below is mainline's, field for field, including the two anonymous
37 * sub-structs (flow, ctrl) -- they are grouped exactly as mainline groups them
38 * because tty_io.c, n_tty.c and serial_core.c all reach for them by member
39 * name, and a field that is present but differently named is indistinguishable
40 * from a missing one at compile time until the error message.
41 */
