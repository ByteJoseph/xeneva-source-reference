drm_exec_until_all_locked - loop until all GEM objects are locked @exec: drm_exec object

Core functionality of the drm_exec object. Loops until all GEM objects are locked and no more contention exists. At the beginning of the loop it is guaranteed that no GEM object is locked.

A global label name drm_exec_retry is used, if you need to use more than one instance of this macro in the same function the label needs to be made local to the block with the label keyword.
