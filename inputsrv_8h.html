#define INPUTSRV_IOC_INJECT   0x5401 /* arg: InputsrvEvent */

Shared kernel/user ABI between the kernel input layer and a user-space input server (Process/inputsrv), via /dev/inputsrv (daemons group only).

The server owns the input hardware through /dev/hwdev and does all the device work: virtio negotiation, interrupts, and decoding raw device events. It hands the kernel DECODED events, which the kernel feeds into the same input layer the in-kernel drivers used (AuDevWriteKybrd / AuDevWriteMice), so the compositor and everything else is unaware of the difference.
