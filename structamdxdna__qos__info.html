Detailed Description

struct qos_info - QoS information for driver. @gops: Giga operations per second. @fps: Frames per second. @dma_bandwidth: DMA bandwidtha. @latency: Frame response latency. @frame_exec_time: Frame execution time. @priority: Request priority.

User program can provide QoS hints to driver.
