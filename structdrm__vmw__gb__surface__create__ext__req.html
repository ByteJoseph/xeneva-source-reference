Detailed Description

struct drm_vmw_gb_surface_create_ext_req

@base: Surface create parameters.

Version
: Version of surface create ioctl. @svga3d_flags_upper_32_bits: Upper 32 bits of svga3d flags. @multisample_pattern: Multisampling pattern when msaa is supported. @quality_level: Precision settings for each sample. @buffer_byte_stride: Buffer byte stride. @must_be_zero: Reserved for future usage.

Input argument to the DRM_VMW_GB_SURFACE_CREATE_EXT Ioctl. Part of output argument for the DRM_VMW_GB_SURFACE_REF_EXT Ioctl.
