Detailed Description

struct folio_batch - A collection of folios.

The folio_batch is used to amortise the cost of retrieving and operating on a set of folios. The order of folios in the batch may be significant (eg delete_from_page_cache_batch()). Some users of the folio_batch store "exceptional" entries in it which can be removed by calling folio_batch_remove_exceptionals().
