Detailed Description

DOC: rect utils

Utility functions to help manage rectangular areas for clipping, scaling, etc. calculations. struct drm_rect - two dimensional rectangle @x1: horizontal starting coordinate (inclusive) @x2: horizontal ending coordinate (exclusive) @y1: vertical starting coordinate (inclusive) @y2: vertical ending coordinate (exclusive)

Note that this must match the layout of struct drm_mode_rect or the damage helpers like drm_atomic_helper_damage_iter_init() break.
