4/*
5 * DCL <linux/proc_fs.h> -- Xeneva has no procfs, so this header exists to
6 * resolve the include and to declare what a ported file might reach for.
7 *
8 * None of the nine tty/serial files creates a proc entry: uart_proc_show() is
9 * only *assigned* under #ifdef CONFIG_PROC_FS (serial_core.c:2690), and DCL's
10 * autoconf does not define it -- so the whole /proc/tty/driver/serial path is
11 * compiled out, exactly as on a mainline kernel built without procfs. The
12 * declarations below are what the rest of that path would use, and the
13 * functions answer NULL/void rather than pretending an entry was created:
14 * a caller that checks the return (mainline does, and unwinds) then sees the
15 * truth.
16 *
17 * seq_printf()/seq_puts(), which uart_proc_show() writes through, live in
18 * <linux/seq_file.h> because they are used outside procfs too.
19 */
