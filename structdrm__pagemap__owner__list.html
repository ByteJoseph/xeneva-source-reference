Detailed Description

struct drm_pagemap_owner_list - Keeping track of peers and owners @peer: List of peers.

The owner list defines the scope where we identify peers having fast interconnects and a common owner. Typically a driver has a single global owner list to keep track of common owners for the driver's pagemaps.
