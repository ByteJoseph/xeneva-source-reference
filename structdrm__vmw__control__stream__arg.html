Detailed Description

struct drm_vmw_control_stream_arg

@stream_id: Stearm to control @enabled: If false all following arguments are ignored. @handle: Handle to buffer for getting data from. @format: Format of the overlay as understood by the host. @width: Width of the overlay. @height: Height of the overlay. @size: Size of the overlay in bytes. @pitch: Array of pitches, the two last are only used for YUV12 formats. @offset: Offset from start of dma buffer to overlay. @src: Source rect, must be within the defined area above. @dst: Destination rect, x and y may be negative.

Argument to the DRM_VMW_CONTROL_STREAM Ioctl.
