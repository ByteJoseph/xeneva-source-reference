NetSurf QuickJS host implementation. See js.h.

One QuickJS runtime/context per page. Inline <script> bodies are fed to NsJsScriptChunk by the HTML pass and evaled at </script>, so document order and JS-side text injection line up with the rendered page. The context outlives the parse so setTimeout/setInterval callbacks keep firing from the GUI loop until the next page replaces it.

Host shell. getElementById returns a live node once NsJsSetDocument is called; setAttribute("style") updates that node's inline sheet. Lookups before the DOM exists, and every other DOM call, stay soft: console.log/info/warn/error/debug -> styled lines through the sink document.write/writeln -> inline text through the sink document.title -> get/set (title scan preloaded) location.href/replace/assign -> queued navigation (fetched by the caller) document.cookie -> the shared HTTP cookie jar navigator.userAgent -> same Chrome string the fetch sends alert(...) -> warning line setTimeout/setInterval/clear* -> timer slots driven by NsJsTick; callbacks may be functions or source strings requestAnimationFrame -> setTimeout(16ms) compat shim window -> alias of globalThis
