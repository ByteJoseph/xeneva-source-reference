Detailed Description

struct virtio_dma_buf_ops - operations possible on exported object dma-buf @ops: the base dma_buf_ops. ops.attach MUST be virtio_dma_buf_attach. @device_attach: [optional] callback invoked by virtio_dma_buf_attach during all attach operations. @get_uid: [required] callback to get the uuid of the exported object.
