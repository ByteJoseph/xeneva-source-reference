math.h shim for the QuickJS port on XenevaOS.

XEClib's real math.h declares only a subset of double libm calls; the rest live in port/libm.c (filling the double-precision gap on top of XEClib's float primitives). quickjs.c needs correct prototypes for all of them plus INFINITY/NAN/signbit – so the QuickJS port build resolves <math.h> to this header instead (include order puts Ports/quickjs/port first for this library only).

Double libm for the QuickJS port.

XEClib ships sin, cos, tan, sqrt, pow, fabs, floor, ceil, fmod, and frexp. QuickJS also calls the functions below. This file is what produces the object; nothing here is a checked-in binary.
