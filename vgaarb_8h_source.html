1/*
2 * DCL <linux/vgaarb.h> -- the VGA-arbiter surface virtio-gpu's init reads.
3 *
4 * mainline's header is the arbiter's client API behind CONFIG_VGA_ARB. There
5 * is no arbiter here, and nothing on this platform's display path wants one:
6 * the device the port runs against (virtio-gpu-pci) reports class 0x0380, so
7 * pci_is_vga() is false and both call sites -- vga_get_interruptible() and
8 * vga_put(), virtgpu_drv.c:190-204 -- sit in a branch that is never taken.
9 *
10 * The two functions are therefore mainline's own !CONFIG_VGA_ARB answers:
11 * the resource bits are unconditional in upstream's header, and with the
12 * arbiter compiled out the get/put calls become calls that succeed and do
13 * nothing. That is not a placeholder for a future arbiter; it is the honest
14 * description of a bus with one display function whose legacy decode
15 * nothing else shares or routes.
16 */
