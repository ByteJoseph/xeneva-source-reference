enum AuResKind

Component model: runtime load/unload bookkeeping for loadable drivers.

A driver is a component with an explicit lifecycle: load -> AuDriverMain() -> [running, refcounted] -> AuDriverUnload() -> freed The kernel records what a driver acquires (IRQ handlers today) keyed by the caller's return address, so unloading releases everything even if the driver forgot to. Physical pages, MMIO and timers are tracked next.

int AuDriverUnload ( AuDriver *  drv)

AuDriverUnload – unload a running driver.

Order matters: ask the driver first (it may veto), then cut every kernel -> driver path BEFORE the image is unmapped: IRQ handlers are cleared and the driver's MMIO mappings removed. Physical pages the driver still owns are only REPORTED, never force-freed: the kernel may have taken them over without telling the ledger, and a leak is safe where a double free is not. Returns an AU_UNLOAD_* code.
